# KantinPay ITK — Sistem E-Wallet Kantin

Proyek UTS Pemrograman Berorientasi Objek (TE2514027)
Institut Teknologi Kalimantan — Semester Genap 2025/2026

## Deskripsi
Sistem e-wallet kantin kampus berbasis OOP (Kotlin) dengan enkapsulasi ketat.

## Entitas
- Mahasiswa (saldo & PIN bersifat private)
- StandMakanan (daftar menu bersifat private)
- Menu (stok bersifat private)

## Business Rules
- Pembelian hanya sah jika PIN benar
- Saldo mahasiswa harus mencukupi
- Stok menu harus > 0
- Saldo tidak boleh minus

## Cara Menjalankan
Buka file KantinPayITK.kt di Kotlin Playground atau IntelliJ IDEA
